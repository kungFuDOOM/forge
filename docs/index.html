Why Forge exists

Humans built Python and JavaScript for humans. Agents forced into those languages fight syntax, precedence, and framework glue. Forge is the agent loop as a language.

A complete agent program

Loop, think, act, verify, return. One program, one run.

AGENT "page-digest"

MEMORY { urls: ["https://example.com", "https://iana.org"] }

FOR EACH url IN $urls OUTPUT digests
  STEP fetch TOOL http_get INPUT { url: $url } OUTPUT page
  IF $page.status == 200
    REASON "One-sentence summary" ON $page.text OUTPUT s
    YIELD { url: $url, summary: $s }
  END
END

VERIFY $digests != []

RETURN $digests
